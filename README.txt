================================================================================
DARK SOULS III - DARK SOULS II HEXES OVERHAUL
================================================================================

A complete overhaul restoring the iconic Hex magic system from Dark Souls II
into Dark Souls III. Includes original Dark Souls II INT & FTH stat requirements,
heavy DS2 spell damage scaling, the Sunset Staff with native animations,
catalysts, armor, progressive shop unlocking via Umbral Ashes, and lore-accurate
boss hex resistances.

================================================================================
INSTALLATION INSTRUCTIONS
================================================================================

Choose either Method 1 (Direct / Simplest) or Method 2 (Mod Engine 2):

--------------------------------------------------------------------------------
METHOD 1: DIRECT INSTALLATION (NO MOD MANAGERS NEEDED - RECOMMENDED)
--------------------------------------------------------------------------------
1. Locate your Dark Souls III Game folder:
   - Steam Default:
     C:\Program Files (x86)\Steam\steamapps\common\DARK SOULS III\Game\
   - Or right-click Dark Souls III in Steam -> Manage -> Browse local files -> Game

2. (Optional but recommended) Make a backup of your original "Data0.bdt"
   file (e.g. rename a copy to "Data0.bdt.bak").

3. Copy the "Data0.bdt" from this folder and paste it into your Dark Souls III
   "Game" folder, replacing the existing file.

4. Launch the game normally via Steam or DarkSoulsIII.exe!

--------------------------------------------------------------------------------
METHOD 2: MOD ENGINE 2 / MOD MANAGER INSTALLATION
--------------------------------------------------------------------------------
1. If you use ModEngine 2:
   - Copy the "mod" folder from this download into your ModEngine 2 directory
     (or into your game's directory if configured).
2. Launch using your standard ModEngine 2 launcher.

================================================================================
HOW TO UNINSTALL
================================================================================
- If you used Method 1: Restore your original "Data0.bdt" backup (or verify game
  files on Steam).
- If you used Method 2: Delete the "Data0.bdt" from your ModEngine 2 "mod" folder.
